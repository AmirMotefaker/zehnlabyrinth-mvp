# هزارتوی ذهن · هستهٔ Godot

این پوشه هستهٔ بازی را از نمونهٔ وب جدا می‌کند تا بازی با یک کدبیس در Android، iOS و Web منتشر شود.

## معماری

- `core/beam_solver.gd`: حل‌کنندهٔ قطعی پرتو
- `core/puzzle_session.gd`: وضعیت مرحله، حافظهٔ دوپالس، امتیاز و راهنما
- `ui/board.gd`: رندر و ورودی لمس/کلیک
- `scripts/game_root.gd`: رابط مرحله و چرخهٔ بازی

## راه‌حل مرحلهٔ شبکهٔ عصبی

1. پالس اول رله‌های ۱ و ۲ را روشن می‌کند.
2. آینهٔ شارژشونده خودکار برعکس می‌شود.
3. پالس دوم رلهٔ ۳ و ستاره را روشن می‌کند.
4. راهنما فقط یک قطعهٔ نادرست را اصلاح می‌کند و ۲۵ امتیاز از پاداش همان مرحله کم می‌کند.

## خروجی

- Android: AAB
- iOS: پروژهٔ Xcode از روی macOS
- Web: HTML5/PWA تک‌ریسمانی
